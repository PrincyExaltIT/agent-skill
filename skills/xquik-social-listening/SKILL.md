# Xquik Social Listening

Use this skill to design a Xquik workflow for X/Twitter research, monitoring,
audience analysis, or webhook-driven follow-up.

Read `ORCHESTRATION.md` first. It defines the provider-neutral process, public
references, safety checks, and output format.

Before making a plan, confirm the user has a valid Xquik API key or OAuth access
for authenticated workflows. Never ask the user to paste secrets into files,
issues, pull requests, or long-lived chat context.
